The model parameter must match exactly one of those names. Chat models go to /v1/chat/completions; embedding models go to /v1/embeddings. Each endpoint enforces its own list, so a chat model is rejected by /v1/embeddings, and the other way around.

Authentication

API endpoints require the header:

Authorization: {{ auth_scheme }} <your-api-key>

Keys are defined in GATEWAY_API_KEYS, comma-separated.

cURL

curl -sS {{ base_url }}v1/chat/completions \
  -H "Authorization: {{ auth_scheme }} <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "{{ models[0] }}", "messages": [{"role": "user", "content": "hello"}], "max_tokens": 200}'

OpenAI SDK (Python)

from openai import OpenAI

client = OpenAI(base_url="{{ base_url }}v1", api_key="<your-api-key>")

r = client.chat.completions.create(
    model="{{ models[0] }}",
    messages=[{"role": "user", "content": "hello"}],
    max_tokens=200,
)
print(r.choices[0].message.content)

Embeddings

curl -sS {{ base_url }}v1/embeddings \
  -H "Authorization: {{ auth_scheme }} <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "{{ embedding_models[0] }}", "input": ["how do I reset my password?", "¿Cómo restablezco mi contraseña?"], "dimensions": 512}'

input accepts a single string or a list of strings; the response carries one embedding per item, in the same order. dimensions truncates the vector, so you can trade a little recall for a much smaller index. Token IDs are not supported.

Embeddings SDK (Python)

r = client.embeddings.create(
    model="{{ embedding_models[0] }}",
    input=["hola mundo", "hello world"],
    dimensions=512,
)
print(len(r.data), len(r.data[0].embedding))

Streaming

curl -N {{ base_url }}v1/chat/completions \
  -H "Authorization: {{ auth_scheme }} <your-api-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "{{ models[0] }}", "messages": [{"role": "user", "content": "hello"}], "stream": true}'

Notes

  • max_tokens: when omitted, Ollama generates without a cap (the model stops on its own). Send it for bounded answers.
  • Gateway default reasoning effort: {{ default_reasoning_effort }}. If the model is reasoning-only, it may return a <think>…</think> block inside content; the gateway does not strip it.
  • Errors use the OpenAI shape: {"error": {"message": …, "type": …, "code": …}}.
  • There is no /v1/images or /v1/completions: chat, embeddings and models only.
